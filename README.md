# Libro Patrimonio (PWA)

## Pubblicare su GitHub Pages
1. Crea un repository su GitHub e carica **tutti** i file di questa cartella nella root (con `icons/` e `.nojekyll`).
2. Settings -> Pages -> Deploy from a branch -> `main` / `(root)` -> Save.
3. Dopo 1-2 minuti l'app e' su `https://TUO-UTENTE.github.io/NOME-REPO/`.

## Installare su iPhone
Apri l'URL con Safari -> Condividi -> "Aggiungi alla schermata Home".

## Dati
I dati stanno in localStorage: sono separati tra Safari e app installata e tra dispositivi. Fai un backup prima di installare e ogni tanto dopo.

## Aggiornare
Sostituisci solo `index.html` nel repo (rinomina il nuovo file in `index.html`). Non serve altro.
